# Personal Introduction Website

A personal portfolio-style website built to introduce myself, showcase my interests, and provide a simple way to connect with me.

## Features

- Personal introduction and profile section
- About Me section
- Skills and interests showcase
- Photography and reading sections
- Interactive popups for exploring interests
- Contact section with social links
- Responsive design for different screen sizes
- Clean and modern user interface
- Deployed as a static website using Vercel

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Vercel
